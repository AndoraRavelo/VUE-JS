## 🎯 Comment ça marche ?

1. **Tu lis le cours** (.md) pour comprendre le concept
2. **Tu essaies l'exercice** dans ton fichier `App.vue`
3. **Tu testes** en lançant `npm run dev` dans ton terminal
4. Si tu es bloquée, tu m'indiques et on regarde ensemble !

---

## 🚀 Pour lancer ton projet

```bash
# Dans ton terminal, va dans le dossier du projet
cd mon-projet-vue

# Lance le serveur de développement
npm run dev
```

Puis ouvre ton navigateur sur **http://localhost:5173** 🌐
